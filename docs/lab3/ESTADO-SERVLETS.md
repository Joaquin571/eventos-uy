Ningún test actual verifica las funciones no implementadas.

Servicios: **P** = PortalService/PortalPublicador, consumido por ClienteCentral; **S** = SesionesService/SesionesPublicador, consumido por ClienteSesionesCentral. Todos sobre HTTPS. La portada usa P.listarEventosPorCategoria; no se atribuye ese recorrido al cliente histórico EventosPublicador.listarEventos.

Rutas JSP relativas a `webapp/src/main/webapp/WEB-INF/views/`; JS a `webapp/src/main/webapp/js/`. Java de Servlet en `webapp/src/main/java/web/`; Sistema en `logica/src/main/java/implementacion/Sistema.java`. Las referencias a pruebas son clases reales, ubicadas en webapp/src/test/java/web (SOAP bajo soap/) o logica/src/test/java/implementacion. No todos los casos de cada Servlet tienen un recorrido HTTP real independiente: las capas de prueba se indican sin confundir dobles con despliegue.

## Fronteras y reglas transversales comprobadas

1. FiltroAcceso usa rutas/roles para UX, revalida usuarioActual ante P03 y traduce SESION_INVALIDA a login, ACCESO_DENEGADO a 403 y NO_ENCONTRADO a 404; fallos técnicos producen página propia 503. Ningún control exclusivamente Web se considera autorización de negocio suficiente.
2. PortalPublicador deriva Actor con SesionesRemotas.requerirActor; Sistema valida rol, propiedad y visibilidad. Las consultas públicas usan actor opcional. El token no es un parámetro SOAP ni va a JSP/URL; ClienteCentral lo envía por encabezado Bearer.
3. Las cinco operaciones multipart llaman una operación compuesta. Subidas no valida formatos por extensión: limita lectura y Central usa ValidadorImagen. Transacción en manejadores, no en Servlet. CSRF no sustituye las validaciones de Sistema.
4. Costos, fechas y nombres se formatean en Web; fecha de alta/registro, costo calculado, propiedad y disponibilidad definitiva pertenecen a Sistema. AltaEdicion/AltaPatrocinio arman DTO con fecha local, pero Sistema la sustituye: no es fuente de autoridad ni requisito para mover el reloj de negocio a Tomcat.
5. JSP usan c:out/c:url para datos y enlaces; formularios POST incluyen fragmento CSRF. En esta revisión se comprobaron sus acciones, scripts y consumidores. La inspección de fuente no sustituye un recorrido visual completo.
6. No hay Servlet para ranking Swing ni debe crearse uno por J04. El nuevo filtro de visitas NO será el Servlet número 22. Los nuevos controladores de seguimiento/archivo/asistencia/PDF/búsqueda/móvil pertenecen a 3/4/5 y requieren contratos primero.
